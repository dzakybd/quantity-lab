How much can a 2-pixel error distort a floor-plan estimate?

quantity-lab measures room area, perimeter and count on floor plans three ways: the annotated rooms (oracle), the same rooms with a controlled error, and a classical OpenCV baseline that labels the free space between walls. Units are image pixels; no physical scale is claimed.

uv run python -m quantity_lab --input plan.pdf --annotations model.svg --mode perturbed --perturbation erode --pixels 2 --output out/plan

Code (MIT): github.com/dzakybd/quantity-lab. Write-up: dzaky.ai.id. Results were computed ahead of time; this page runs no model.
